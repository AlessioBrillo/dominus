No EUIPO registration for the DOMINUS name has been filed. A formal search has
not been run yet: the EUIPO/TMview search is a human task, to be performed and
recorded by the operator before the paid launch. The intended filing is in

filed 27 June 2025, serial 99255938. This is an exploratory finding only. It is
not a formal search, not an opinion on registrability, and not a clearance for
the name in any jurisdiction.

The formal EUIPO/TMview search and the decision to file in classes 9 and 42
are preconditions of the paid launch. Until they are done, nothing in this
repository should be read as a claim that the name is registered or available.
